## Preguntas de reflexión
1. **¿Cuál es la diferencia entre una base de datos y una tabla?**[span_22](start_span)[span_22](end_span)
   Una base de datos es el contenedor general de información[span_23](start_span)[span_23](end_span), mientras que una tabla es la estructura organizada en filas y columnas dentro de la base de datos[span_24](start_span)[span_24](end_span).
2. **¿Qué diferencia existe entre una fila y una columna?**[span_25](start_span)[span_25](end_span)
   Una fila (registro) representa una ocurrencia individual de datos[span_26](start_span)[span_26](end_span), mientras que una columna (campo) es un atributo que describe los registros[span_27](start_span)[span_27](end_span).
3. **¿Para qué sirve SELECT?**[span_28](start_span)[span_28](end_span)
   Sirve para consultar y extraer información almacenada en las tablas[span_29](start_span)[span_29](end_span)[span_30](start_span)[span_30](end_span).
4. **¿Para qué sirve WHERE?**[span_31](start_span)[span_31](end_span)
   Permite filtrar registros estableciendo una condición específica en las consultas, modificaciones o eliminaciones[span_32](start_span)[span_32](end_span)[span_33](start_span)[span_33](end_span).
5. **¿Qué función tiene UPDATE?**[span_34](start_span)[span_34](end_span)
   Modifica la información contenida en registros existentes dentro de una tabla[span_35](start_span)[span_35](end_span)[span_36](start_span)[span_36](end_span).
6. **¿Por qué es importante utilizar WHERE al modificar información?**[span_37](start_span)[span_37](end_span)
   Porque si se ejecuta UPDATE sin WHERE, se cambiarán los datos de todas las filas de la tabla de forma no deseada[span_38](start_span)[span_38](end_span).
7. **¿Qué puede ocurrir si utilizamos DELETE sin WHERE?**[span_39](start_span)[span_39](end_span)
   Se eliminarán absolutamente todos los registros presentes en la tabla[span_40](start_span)[span_40](end_span).
8. **¿Qué tipo de información se puede almacenar en una columna INT?**[span_41](start_span)[span_41](end_span)
   Números enteros (positivos o negativos) sin parte decimal[span_42](start_span)[span_42](end_span).
9. **¿Qué diferencia existe entre INSERT, UPDATE y DELETE?**[span_43](start_span)[span_43](end_span)
   INSERT agrega registros nuevos[span_44](start_span)[span_44](end_span)[span_45](start_span)[span_45](end_span), UPDATE modifica datos existentes[span_46](start_span)[span_46](end_span)[span_47](start_span)[span_47](end_span) y DELETE elimina registros de la tabla[span_48](start_span)[span_48](end_span)[span_49](start_span)[span_49](end_span).
